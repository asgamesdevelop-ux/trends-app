# Тренды — аналитика мобильных игр

Личный трекер трендов Google Play: топы 8 рынков, радар свежих взлётов, карточки игр с историей, утренняя сводка в Telegram.

- Приложение: `https://<логин>.github.io/<репозиторий>/` — ставится на телефон и компьютер (PWA).
- Данные собирает GitHub Actions каждый день в 09:35 по Турции (`.github/workflows/daily.yml`).
- Сборщик: `collector/collector.mjs`, сводка: `collector/notify.mjs`, данные: `data/`.
